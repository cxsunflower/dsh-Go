# 像素奶蛙（宠物包 `naiwa`）

来自 github.com/cxsunflower，形象参考网络二创『奶蛙』用脚本重画，非官方，仓库不含任何参考图。

经典黄色版本：梨形身体，头和身子连成一体，没有脖子；奶油色肚皮，浅绿色眼圈配黑瞳孔，灰褐色的小爪和脚。大笑时眼睛弯成两道弧，嘴巴张到半张脸那么大。所有帧都由 `draw.py` 用 numpy + Pillow 逐像素画出，不读取任何外部图片。动画清单和状态映射见 [docs/design/naiwa-pet.md](../../../../docs/design/naiwa-pet.md) 第 2 节。

## 文件

| 文件 | 说明 |
|---|---|
| `draw.py` | 生成脚本，唯一的源文件 |
| `pet.json` | 由 `draw.py` 写出：帧时长、状态映射、档位、待机池与反应 |
| `sheets/<anim>.png` | 由 `draw.py` 写出，1 倍单行横条，每帧 64×64，共 24 段 |
| `docs/assets/naiwa-frames.png` | README 展示的全部 861 帧大图，由 `draw.py --preview` 生成 |
| `docs/assets/naiwa/*.gif` | README 的 24 段动作预览，由 `draw.py --gallery` 按原时长生成，3 倍放大并循环展示 |
| `docs/assets/naiwa-attention.gif` | 完成状态演示：轻跃、“啦”口型与 ✅ → 待机；由 `draw.py --completion-previews` 生成 |

`pet.json` 和 `sheets/` 是生成物，不要手改，改 `draw.py` 后重新生成。

## 重新生成

在仓库根目录运行（需要 numpy 和 Pillow）：

```bash
python app/tool/pet_src/naiwa/draw.py              # 重画并写出 sheets/ 和 pet.json，然后自检
python app/tool/pet_src/naiwa/draw.py --check      # 只在内存里重画并自检；磁盘上的文件过期也算失败
python app/tool/pet_src/naiwa/draw.py --preview    # 另写全帧总览 app/build/pet_src_preview/naiwa.png
python app/tool/pet_src/naiwa/draw.py --check --preview docs/assets/naiwa-frames.png  # 更新 README 全帧大图
python app/tool/pet_src/naiwa/draw.py --check --gallery docs/assets/naiwa  # 更新 README 全部 GIF 预览
python app/tool/pet_src/naiwa/draw.py --check --completion-previews docs/assets  # 完成状态与返回待机的顺序预览
python app/tool/pet_src/naiwa/draw.py --strip celebrate laugh-roll   # 另写单段放大图 app/build/pet_src_preview/naiwa/<anim>.png
python app/tool/pet_src/naiwa/draw.py --check --strip crawl --gif crawl  # 逐帧图与原速 GIF 预览
python app/tool/pet_src/naiwa/draw.py --check --strip carrying annoyed laugh-roll --gif carrying annoyed laugh-roll
```

脚本不读时钟、不用随机数，两次运行的输出字节相同。打包试跑（只输出到 `app/build/`）：

```bash
python app/tool/make_pet_pack.py --only naiwa --out app/build/pet_try --preview app/build/pet_try_preview
```

## 画布与尺寸

- 画布 64×64，透明像素一律是 `(0, 0, 0, 0)`，其余 alpha 都是 255，不抗锯齿。
- 待机身体约 30×34：躯干最宽 30 像素（含描边），加上两侧小爪是 32 像素，占 x 16–47；高 34 像素，占 y 26–59。
- 身体中轴 x = 32，脚底线 y = 60（最低的不透明行是 59）。待机各帧脚底线不变，不带离体道具。
- 直立进食的嘴中心是 (32, 39)，是张大嘴（10×8 的 `eat` 嘴形）的中心。直立进食动画的张嘴帧都在该中心 ±1 像素以内。趴行保持微笑，不张嘴进食。

## 画法

- 躯干是绕 x = 32 的逐行半宽轮廓：圆顶、两侧向下变宽、低处的肚子、圆底。头部使用固定轮廓，按整像素平移，随翻滚整体旋转，不参与呼吸或倾斜时的缩放、斜切。胸腹在固定的头部与髋线之间伸缩，连接处宽度与头部一致。
- 肚皮是躯干内的椭圆，手臂是两段胶囊加一个小圆爪，腿是短胶囊加半椭圆脚。所有动作按正视待机统一上臂约 4.61 像素、前臂 4 像素、爪半径 1.75 像素，趴爬共用这组尺寸。手臂跟随肩膀整体移动，不随胸腹伸缩而扭曲；绘制时肩肘统一到半像素关节坐标，前臂连接手掌的整数落点，减少手掌停住时周围轮廓逐点变化。前臂的黄色填色收在腕线后方，不越过手掌末端。待机双臂保持形状，随呼吸整体轻微起伏；抬手、挥手和伸懒腰通过转动关节完成。
- 光从左上来：右下边缘两级暗部，头顶一块高光。描边是所有部件的 4 邻域膨胀减去部件本身；挡在躯干前面的手臂在重叠处也有自己的描边。
- 描边统一收成 1 像素线：肢体的描边与躯干、头或箱子的描边并排时，肢体向相邻描边补 1 像素，不叠成双线；描边围出的 1 像素小孔和窄缝直接连成线，轮廓上顶出的单个像素削掉。躯干、头和箱子保持原形，箱子只用自带的边框，不另加外描边。肚皮暗部不留孤立的单像素。
- 眼睛、嘴、道具是手绘的小位图，按骨架锚点盖上去；左右对称的五官按中轴对称取整，落在镜像的像素上。眼嘴共用纵向落点并保持间距，避免不同高度的位图各自取整，导致嘴巴先动、眼睛后动。
- 待机每 2540 ms 完成一次轻呼吸，胸腹和双臂舒展，头部保持形状、只轻微平移，脚底固定在 y = 60；捂嘴偷笑也只抖动上身，不抬起整只宠物。趴行后脚为较薄的圆头椭圆；后腿与臀部连成一体，仅描合并后的外轮廓，交界处不再额外描黑边，臀部左侧以更圆的像素阶梯过渡。
- 离体道具（哈、Z、!、?、代码字符和方块、碎屑、汗滴）带 8 邻域描边，并和身体至少隔 1 个透明像素，打包工具按「最大连通块」找身体。爪里拿着的道具和鼻涕泡贴着身体。
- 全部动作按各自节奏补入身体、手臂、脚步和道具过渡帧：手臂按关节角度插值后，以固定臂长重画；保持像素边缘清晰，不混合相邻图片。工作、子代理和压缩均为 50 ms 一帧；完成和三连点的节奏保留。
- 每个部件按整像素、在同一帧一起移动：整体位移、脚掌、肚皮起伏和趴行小腿先取整再绘制，脚掌保持站立时的形状；手臂只在手掌跨到下一个像素时重画，躯干不做横向缩放。否则头、胯、脚会在不同帧越过取整点，播放时像波浪一样沿身体爬行。
- 完成动作直接张口做“啦”的口型；开口沿用进食嘴型的 8 像素高度，露出上排牙齿和更宽的舌头。张嘴和收口经过笑嘴与半张口过渡，口型节奏独立于身体插值。双爪张开配合轻跃，绿色 ✅ 悬在头顶，始终与身体隔开，最后闭眼、微笑回到待机。
- 工作采用键盘动作：键盘画在躯干之前、双臂之后，后沿窄、前沿深，像略带俯视。爪子落在键上，被敲的键闪白再转蓝；爪子只落在肩膀正下方或内侧，短臂不会折起、把手肘甩成翅膀。每次击键在头顶放出一个代码字符，字符与身体保持透明间隔。子代理用带 `>_` 的终端小图标区分单个与多个；上下文压缩用连续长纸，只有实际进入嘴部的纸张允许遮挡嘴型。
- 搬运的小箱子贴在肚前，先画箱子再画双臂与爪，手掌握住左右边缘；箱子随身体同步移动，不遮眼睛和嘴。胶带、白色标签与向下箭头帮助辨认导入场景。

## 状态映射

| 场景 | 动画 |
|---|---|
| 待机 / 思考 / 游走 | `idle` / `thinking` / `walk` |
| 工作 | 1 个会话 `typing`，2 个 `typing-both`，3 个及以上 `typing-fast` |
| 子代理 | 1 个 `terminal`，2 个及以上 `terminals` |
| 出错 / 完成 / 待确认 | `shocked` / `celebrate` / `alert` |
| 上下文压缩 / 导入宠物包 | `eat-paper` / `carrying` |
| 睡眠 / 唤醒 | `sleep` / `wake` |
| 左右点按 | `poke-left` / `poke-right` |
| 三连点反应 | `laugh-roll` |
| 六连点 / 拖动 | `annoyed` / `crawl` |

- 待机池四项 `idle-look`、`idle-giggle`、`snack`、`dance` 权重均为 1，分别播放 2、2、1、2 遍。
- 聊天页正常待机时每次等待 10–25 秒后插播。间隔参数为 `min: 10000`、`mean: 18000`、`max: 25000`；无任务且 60 秒无交互后休眠，插播不延后休眠。
- 完成态每次播放一遍 `celebrate`，共 2080 ms，再返回当前状态；`holds.attention` 为 1，`bonus` 为空。`dance` 只在待机池中出现。
- `reactions.tickle` 指向 `laugh-roll`，保留 main 的反应入口名。1.1 秒内第 3 下开始捧腹大笑、打滚与起身的连贯动作，第 4、5 下重新播放，第 6 下转为 `annoyed` 并清空计数。前 24 帧捧腹起伏，每帧 60 ms，共 1440 ms；后续 25 帧屈身、打滚和起身共 1500 ms。
- 导入期间循环播放 `carrying`；六连点播放一次 `annoyed`。反应由 App 计时结束，不按录音延长。
- 包按 main 的无声接口制作，不含 `sounds`、`snack`、`roam.free` 或 `drag.mirror`。动画中的代码字符都在图片中。
- 悬浮窗不触发游走或连点反应。声音输入、已生成音频与来源说明保留在仓库中，见 [audio/README.md](audio/README.md)，不随宠物 ZIP 或 APK 打包。

## 自检

`draw.py` 每次运行都会检查下面这些，`--check` 还会核对磁盘上的文件是否最新：

- 24 段名字齐全，每段 4–64 帧、每帧 40–400 ms、总帧数不超过 1024、每段不超过 256 色。alpha 只有 0 和 255，透明像素全是 `(0, 0, 0, 0)`，PNG 读回来和画出来的逐像素相同。
- 待机各帧脚底线都是 y = 60，只有一个连通块，没有离体道具。
- 待机双臂与手掌平移对齐后形状固定，手掌末端的描边范围不能露出黄色填色。逐帧检查左右手臂最外沿及其外侧一像素：手臂位置未变时，该处不能出现胸腹横向缩放造成的凸点。趴行保留后腿与臀部之间原有的分层接缝。
- 所有未旋转的正面动作，头部平移对齐后，轮廓必须与正视待机逐像素一致。
- 离体道具离身体（含手持道具）至少 1 个透明像素；每帧最大的 8 连通块正好是身体。
- `celebrate`、`wake`、`poke-left`、`poke-right`、`laugh-roll`、`annoyed` 不循环，最后一帧和待机第 0 帧的重合度（IoU）不低于 0.9。
- 进食动画张嘴帧的嘴中心在 该中心 ±1 像素以内。
- 全部帧的上臂、前臂长度与正视待机一致，趴爬的爪点落在相同的短臂范围内。逐帧核对完整五官位图，嘴部允许捂嘴、吃进长纸或字符和睡眠气泡的有意遮挡。
- 睁眼和瞪眼在九个注视方向都保留一个白色高光；瞳孔移到眼圈边缘时，高光落在仍可见的瞳孔像素内。皱眉眼型同样保留浅绿眼圈、黑瞳孔和白色高光。
- `pet.json` 引用的动画都存在，每段动画都被用到。
- 能导入 `app/tool/make_pet_pack.py` 时，按它的规则预算点击框并打印出来。
